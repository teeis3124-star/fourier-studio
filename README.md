# Fourier Studio

一个纯浏览器运行的交互式傅里叶可视化工具。从一维傅里叶级数、频谱与旋转相量，进一步扩展到二维复傅里叶绘图。

## v0.4 功能

### 一维 Fourier Studio
- 512 点周期采样，最高 64 阶傅里叶重建
- 鼠标 / 触控笔直接手绘目标周期函数
- 正弦波、方波、锯齿波、三角波、脉冲预设
- 实时显示具体傅里叶级数
- “精简零项 / 完整公式”切换
- 点击公式中的某一项，高亮对应橙黄色谐波
- 一键复制 LaTeX
- 幅度谱、相位谱与 RMS 重建误差
- 一维 Fourier Epicycle 动画
- 暂停、继续、重新播放和速度调节

### 二维 Complex Fourier Drawing
- 在二维画布上自由手绘路径
- 自动将首尾连接为闭合周期路径
- 按弧长均匀重采样为 256 点，减小绘制速度不均匀造成的参数化误差
- 将二维坐标写为复函数 `z(t)=x(t)+iy(t)`
- 计算双边复傅里叶系数 `k=-K,...,K`
- `K` 可从 1 调到 60
- 旋转圆首尾相接实时重画原路径
- 支持暂停、继续、重新播放和 0.25×–3× 速度
- 内置星形示例，打开即可观察效果

## 一维傅里叶级数

在区间 `[-π, π)` 上使用 512 个离散采样点近似：

`f_N(x) = a0/2 + Σ[a_n cos(nx) + b_n sin(nx)]`

其中：

- `a_n ≈ (2/M) Σ f(x_i) cos(n x_i)`
- `b_n ≈ (2/M) Σ f(x_i) sin(n x_i)`
- `M = 512`

第 `n` 阶谐波为：

`h_n(x) = a_n cos(nx) + b_n sin(nx)`

## 一维旋转相量

定义：

`A_n = sqrt(a_n^2 + b_n^2)`

`φ_n = atan2(a_n, b_n)`

则：

`a_n cos(nt) + b_n sin(nt) = A_n sin(nt + φ_n)`

因此每一阶都可以表示成一个半径为 `A_n`、角速度为 `nω` 的旋转向量。

## 二维复傅里叶原理

手绘路径经过弧长重采样后得到：

`z_j = x_j + i y_j, j = 0,...,M-1`

复傅里叶系数采用离散近似：

`c_k = (1/M) Σ z_j exp(-i 2π k j / M)`

其中 `k=-K,...,K`。

重建路径为：

`z_K(t) = Σ c_k exp(i k t)`

每个复系数 `c_k` 就对应一个旋转圆：

- 半径：`|c_k|`
- 角速度：`k`
- 初相位：`arg(c_k)`

所有向量首尾相接后，最后一个端点随 `t` 运动形成的轨迹，就是当前有限阶复傅里叶重建。
