# Fourier Studio

一个纯浏览器运行的交互式傅里叶可视化工具。从一维傅里叶级数、频谱与旋转相量，扩展到二维复傅里叶绘图，以及文字 / 图片轮廓自动提取。

## v0.5 功能

### 一维 Fourier Studio
- 512 点周期采样，最高 64 阶傅里叶重建
- 鼠标 / 触控笔直接手绘目标周期函数
- 正弦波、方波、锯齿波、三角波、脉冲预设
- 实时显示具体傅里叶级数
- “精简零项 / 完整公式”切换
- 点击公式项高亮对应谐波
- 一键复制 LaTeX
- 幅度谱、相位谱与 RMS 重建误差
- 一维 Fourier Epicycle 动画

### 二维 Complex Fourier Drawing
- 在二维画布上自由手绘路径
- 自动闭合路径并按弧长重采样为 256 点
- 将二维路径表示为复函数 `z(t)=x(t)+iy(t)`
- 计算双边复傅里叶系数 `k=-K,...,K`
- `K` 可从 1 调到 60
- 旋转圆首尾相接实时重画原路径
- 暂停、继续、重新播放和速度调节

### v0.5：文字 / 图片轮廓导入
- 输入任意短文字并自动转成轮廓
- 支持中文与英文，具体字体由本机浏览器字体决定
- 上传 PNG / JPG / WebP 等浏览器支持的图片
- 图片与文字均只在本地浏览器处理，不上传到服务器
- 使用灰度阈值把深色前景从浅色背景中分离
- 阈值可实时调节
- 使用 Marching Squares 从二值图像提取有序闭合边界
- 多个独立轮廓会按最近距离拼接为一条连续路径
- 拼接后的路径直接进入现有复傅里叶系数与旋转圆动画
- 默认仍提供星形示例和自由手绘模式

## 一维傅里叶级数

在区间 `[-π, π)` 上使用 512 个离散采样点近似：

`f_N(x) = a0/2 + Σ[a_n cos(nx) + b_n sin(nx)]`

其中：

- `a_n ≈ (2/M) Σ f(x_i) cos(n x_i)`
- `b_n ≈ (2/M) Σ f(x_i) sin(n x_i)`
- `M = 512`

## 二维复傅里叶

手绘或导入的轮廓最终都被转换为二维路径：

`z_j = x_j + i y_j, j = 0,...,M-1`

复傅里叶系数：

`c_k = (1/M) Σ z_j exp(-i 2π k j / M)`

其中 `k=-K,...,K`。

重建：

`z_K(t) = Σ c_k exp(i k t)`

每个 `c_k` 对应一个旋转向量：

- 半径：`|c_k|`
- 角速度：`k`
- 初相位：`arg(c_k)`

所有向量首尾相接后，最后一个端点的轨迹就是有限阶复傅里叶重建。

## v0.5 轮廓提取流程

文字：

`文字 → Canvas 栅格化 → 灰度二值化 → Marching Squares → 闭合轮廓 → 路径拼接 → 复傅里叶`

图片：

`本地图片 → 缩放到离屏 Canvas → 灰度阈值 → Marching Squares → 闭合轮廓 → 路径拼接 → 复傅里叶`

为了让后续傅里叶参数化更稳定，最终路径仍会按弧长均匀重采样为 256 个点。

### 图片建议

当前 v0.5 最适合：
- 深色图形 + 浅色背景
- Logo
- 图标
- 黑白剪影
- 简单线稿或轮廓图

照片也可以尝试，但复杂纹理通常会产生大量小轮廓；可通过灰度阈值减少噪声。
