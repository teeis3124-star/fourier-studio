# Fourier Studio

一个纯浏览器运行的交互式傅里叶级数可视化工具。

## v0.2 功能
- 512 点周期采样，最高 64 阶傅里叶重建
- 鼠标 / 触控笔直接手绘目标周期函数
- 正弦波、方波、锯齿波、三角波、脉冲预设
- 实时显示具体傅里叶级数
- “精简零项 / 完整公式”切换
- 点击公式中的某一项，高亮对应橙黄色谐波
- 一键复制 LaTeX
- 幅度谱、相位谱与 RMS 重建误差
- 根目录浏览器构建 `js/main.js`
- 可生成单文件离线版本 `dist/Fourier-Studio.html`

## 直接运行
直接用静态服务器打开仓库根目录的 `index.html` 即可。

## 开发
```bash
npm install
npm run test
```

## 数学定义
在区间 `[-π, π)` 上使用 512 个离散采样点近似：

`f_N(x) = a0/2 + Σ[a_n cos(nx) + b_n sin(nx)]`

其中：
- `a_n ≈ (2/M) Σ f(x_i) cos(n x_i)`
- `b_n ≈ (2/M) Σ f(x_i) sin(n x_i)`
- `M = 512`

橙黄色曲线表示当前选中的第 `n` 阶谐波：

`h_n(x) = a_n cos(nx) + b_n sin(nx)`

它是最终 N 阶重建曲线中的一个组成部分。
